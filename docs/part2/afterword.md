# 第 2 部のおわりに　木は完成した、次は言葉を教える

第 2 部を完走しました。手元には次の資産があるはずです。

- **知識** — ファンアウトと高さの関係、B-Tree と B+Tree の違い、リーフ分割(コピー)と内部ノード分割(昇格)の非対称性、フリーリストによるページの再利用、LRU キャッシュと「dirty は追い出さない」という整合性の保ち方
- **コード** — テスト付きの `btree` パッケージ(約 780 行 + テスト)、`pager` パッケージ(約 380 行)、そして自分の木を覗く `treedump` と `deletedemo`

第 1 部で作った `pager` の上に、第 5〜8 章で B-Tree を積み上げました。ページが分割で増え、内部ノードを介して木が育ち、削除で縮み、フリーリストで空きが再利用される — キーと値の組を扱う索引構造として、ひととおりの機能が揃いました。ただし今の Alice のレコードは、まだ `[]byte("Alice,30")` という手作りのバイト列にすぎません。列の型も、カラム名も、`WHERE` も知りません。第 3 部では、この木にレコード形式と SQL という言葉を教えていきます。
