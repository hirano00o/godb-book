# 第 1 部のおわりに　ここまでで作ったもの、ここから作るもの

第 1 部を完走しました。手元には次の資産があるはずです。

- **知識** — データベースが乗り越える 4 つの壁、RDBMS と SQLite の層構造、ページという単位の必然性、SQLite ファイルフォーマットの読み方、fsync の意味
- **コード** — 本物の SQLite ファイルを解析する `cmd/inspect`(約 140 行)と、テスト付きの `pager` パッケージ(約 200 行)

行数こそ小さいものの、この `pager` は今後すべての章のコードが乗る土台です。第 2 部では、この上に本丸 — B-Tree を建てます。ページ 2 に眠っていた 3 つのセル(Alice, Bob, Carol)がどんなバイト列で、どう並び、木がどう育っていくのか。inspect で覗いた `0x0d`(テーブルリーフ)の内側へ、いよいよ踏み込みます。
